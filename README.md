# Boss 求职助手

本地 Chrome 扩展。使用可配置的 OpenAI Chat Completions 兼容 API，批量分析 Boss 职位列表中的 JD，并生成候选人匹配评分、技能缺口与定制招呼语。

## 工作流

1. 在扩展配置中保存 API、简历、投递方向与匹配阈值；保存后会立即回读校验。
2. 打开 Boss 职位搜索列表页，点击右下角“采集并分析本页”。每次最多处理 20 个可识别的岗位链接。
3. 每个岗位都会进入扩展首页的“待人工确认”列表。你可查看匹配分数、关键技能差距和招呼语，并逐条点击“确认发送”或“跳过”。
4. 点击“自动发送已确认项”并在系统确认框中再次确认后，扩展才会发送已确认项。
5. 每条发送间随机冷却 4–6 秒；以浏览器本地日期计，每日最多 150 条。发送失败会保留为“发送失败”，便于检查。

## 安装

1. Chrome 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目文件夹。
4. 在扩展管理页重新加载扩展，以使用新版本。

## 注意

- 需要先登录 Boss 直聘。页面结构变化、风控或登录状态都会导致采集或发送失败。
- 自动发送仅面向你已在队列中逐条确认的岗位；开始前还有一次批量确认。
- API Key、简历和队列数据仅保存在浏览器本机扩展存储中，但分析时简历与 JD 会发送至你配置的模型服务商。
- 请自行确认使用方式符合 Boss 直聘及模型服务商的规则。
