# Boss 求职助手（人工确认版）

这是一个本地 Chrome 扩展：在 Boss 直聘岗位页面上，用你选定的 OpenAI 兼容大模型 API 分析岗位与简历的匹配度，生成针对性招呼语。

**它不会自动发送消息。** 扩展只会在匹配度达到你的阈值后，把文本填进聊天框；你必须亲自在 Boss 页面检查内容并点击原生“发送”按钮。

## 安装

1. 下载或打开本项目文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目文件夹。
5. 点击浏览器工具栏中的扩展图标，填写 API 地址、模型、API Key、投递偏好和简历。

## 使用

1. 登录 Boss 直聘，打开一个具体岗位的详情页。
2. 右下角会出现“求职助手 · 人工确认”面板，点击“分析当前岗位”。
3. 查看匹配度、匹配原因和生成的招呼语，可手动编辑招呼语。
4. 只有达到阈值时，“确认后填入聊天框”可用。点击后，扩展会把内容填入页面聊天框。
5. 再次核对，并由你手动点击 Boss 页面原生的发送按钮。

## API 兼容性与隐私

- API 地址默认遵循 OpenAI Chat Completions 格式，会自动补上 `/chat/completions`。例如 OpenAI 使用 `https://api.openai.com/v1`。
- 你的 API Key 和简历只保存在本浏览器的扩展本地存储中；分析时会发送到你配置的模型服务商。
- 请确认你选择的模型服务及 Boss 直聘的使用规则允许你的使用方式，并避免在简历中提供不必要的敏感信息。

## 已知限制

Boss 页面会更新，聊天输入框的页面结构也可能变化；若找不到输入框，请先在页面中点击“立即沟通”打开聊天窗口后再点击“确认后填入聊天框”。
