# Boss 求职助手（人工确认版）

本地 Chrome 扩展：在 Boss 直聘岗位详情页使用你配置的 OpenAI 兼容大模型，分析岗位 JD 与简历的匹配程度、关键技能差距和补强建议，并生成针对性的招呼语。

**扩展不会自动发送消息。** 它最多把文本填入 Boss 聊天框；你必须核对内容并亲自点击 Boss 页面原生的“发送”按钮。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目文件夹。
4. 点击浏览器工具栏里的扩展图标，填写 API 地址、模型、API Key、投递偏好和简历。

## 使用流程

1. 登录 Boss 直聘，打开一个具体岗位的详情页。
2. 点击右下角“分析当前岗位”。扩展将 JD 发给你配置的大模型。
3. 页面面板会展示匹配评分、匹配依据、关键技能差距、补强建议和可编辑招呼语。
4. 每次分析都会保存到扩展首页的“待人工确认”队列；可查看评分、技能缺口、招呼语，打开岗位或跳过。
5. 只有评分达到你的阈值时，才可点击“确认后填入聊天框”。每次确认后有随机 4–6 秒冷却时间。
6. 你亲自检查聊天框里的内容，然后手动点击 Boss 页面原生的发送按钮。

## API 与隐私

- API 地址遵循 OpenAI Chat Completions 格式；默认地址为 `https://api.openai.com/v1`，扩展会自动补上 `/chat/completions`。
- API Key、简历与待确认队列只保存在浏览器本机的扩展存储中。分析时，简历和当前岗位文本会发送至你选择的模型服务商。
- 请确认模型服务商和 Boss 直聘的平台规则允许你的使用方式，不要提供非必要敏感信息。

## 已知限制

Boss 页面结构可能更新。如未找到输入框，请先在岗位页点击“立即沟通”打开聊天窗口，再使用“确认后填入聊天框”。
